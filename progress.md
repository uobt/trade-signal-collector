## Открытия пилота public/v1/preview (без ключа)

1. Работает без ключа: `GET /public/v1/preview/C/A/HS?...` → 200, полные данные.
2. **Rate limit ~1 запрос/мин**: подряд второй запрос → 429; пауза 75с → 200.
   Транспорт: 429 → пауза ≥30с, ≤2 повторов; между запросами 65с в preview-режиме.
3. **Максимум 1 период на запрос** («Maximum number of periods for preview is 1»)
   → scheduler разворачивает периоды; в data/v1/get — csv-список периодов.
4. **Полная иерархия с total-строками**: partner2=0 (мир), customs C00 (все
   режимы; C00 = C01 + C04), mot=0 (весь транспорт). Наивная сумма удваивает.
   Парсер берёт total-строку; fallback — сумма (partner2=0, mot=0, C01+C04).
   Проверено: контрольная сумма разбивок DEU×CHN×2024 совпала с total
   до центов ($141,462,937.43).
5. Ответ: `{"data": [...], "error": ""}` — совместим с нашей схемой.
